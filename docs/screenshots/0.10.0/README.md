# Gemeinsame Angaben in Bodenwelle 0.10.0

Diese Vorschauen wurden direkt aus den Android-Ansichten mit nativer Robolectric-Grafikverarbeitung auf simuliertem Android 15 gerendert (411 × 891 dp, 420 dpi). Messungen, GPS-Angaben und Beschreibungen sind Beispieldaten. Es sind keine Aufnahmen vom Fairphone; Geräteschrift, Systemleisten und Abstände können abweichen.

| Prüfung einer Einzelmessung mit Hinweis auf gemeinsame Angaben | [gemeinsame-angaben.png](gemeinsame-angaben.png) |

Im Beispiel unterscheiden sich die manuellen Oberflächen von Messung #1 und #2. Ohne Auswahl wird die Bündelung nicht gespeichert. Nach der Auswahl gelten Fotos, Verkehrsfläche, Oberfläche und Gefährdungsmerkmale gemeinsam; die gezeigte Messung #2 bleibt trotzdem einzeln ungeprüft, bis sie ausdrücklich freigegeben wird. Die aufklappbaren Bereiche im zweiten Bild sind geschlossen.

Die Anwendung wurde für diese Vorschau nicht verändert. Die Karte im Hintergrund verwendet regulär geladene OpenStreetMap-Kacheln; © OpenStreetMap contributors.
