# Oberfläche von Bodenwelle 0.9.0

Diese Vorschauen wurden direkt aus den Android-Ansichten mit nativer Robolectric-Grafikverarbeitung auf simuliertem Android 15 gerendert (411 × 891 dp, 420 dpi). Sie sind keine Aufnahmen vom Fairphone. Alle Messungen, Zeitpunkte und die GPS-Anzeige sind Beispieldaten. Geräteschrift und Systemleisten können abweichen.

Die Karte enthält regulär geladene OpenStreetMap-Kacheln für den gezeigten Ausschnitt; © OpenStreetMap contributors. Der Anwendungscode wurde für die Vorschau nicht verändert.
