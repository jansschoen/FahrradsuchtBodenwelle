# Oberfläche von Bodenwelle 0.8.0

Diese Bilder sind direkt aus den Android-Ansichten des veröffentlichten Codes gerendert, mit nativer Robolectric-Grafikverarbeitung auf simuliertem Android 15. Sie sind keine vom Fairphone aufgenommenen Screenshots. Die Darstellung verwendet 411 × 891 dp bei 420 dpi; Geräteschrift, Systemleisten und Abstände können auf dem Telefon abweichen.

Standorte, GPS-Genauigkeit, Zeitpunkte und Fundstellen sind Beispieldaten. Die Bilder zeigen keine tatsächlichen Schadensmeldungen. Die Kartenansicht verwendet regulär geladene OpenStreetMap-Kacheln für den gezeigten Ausschnitt; © OpenStreetMap contributors. Die App-Datei und der Anwendungscode wurden für diese Vorschau nicht verändert.
