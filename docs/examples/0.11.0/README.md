# PDF-Beispiel für Bodenwelle 0.11.0

[Beispielbericht als PDF öffnen](Fundstellenbericht-Beispiel.pdf)

Der dreiseitige Bericht wurde direkt mit der PDF-Erstellung des App-Codes erzeugt. Alle Fundstellen, Messwerte, Höhenangaben und Beschreibungen sind erfundene Beispieldaten, keine tatsächlichen Schadensmeldungen. Die Bilder unten sind direkt aus diesem PDF gerendert.

Der Cloud-Proxy blockiert den Live-Abruf der OSM-Kacheln. Deshalb zeigt das Beispiel ausdrücklich eine **unvollständige Straßenkarte** als Positionsplan mit Nummern, Nordpfeil und Maßstab. Auf dem Handy verwendet die App vorhandene OSM-Kacheln und ergänzt fehlende Teile bei erreichbarem Anbieter. Die Kartenansicht mit vollständig geladenem Cache ist automatisiert geprüft. Das Beispiel ersetzt keinen Live-Kartentest auf dem Fairphone.

Seite 3 enthält die ausdrücklich ausgewählte Beispielnotiz. Die Tabelle verweist darauf. Die unterschiedlichen Stellennummern und lokalen Messungsnummern sind beabsichtigt: Die Stellen sind geografisch geordnet, die ursprünglichen Messungsnummern bleiben erhalten. Die acht Millimeter stammen im Beispiel aus einer als manuell gemessen gekennzeichneten Angabe; die App berechnet sie nicht aus der Beschleunigung.
